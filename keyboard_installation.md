## How to install a Deseret alphabet keyboard

You will need to download an application called Keyman to install custom keyboards on your computer. You can download Keyman by selecting the Deseret keyboard at this link: 
https://keyman.com/keyboards/deseret 

Click 'install keyboard' and follow the setup instructions.
Remember to download new versions of Keyman as soon as updates are released, as this will prevent issues with displaying your text.

This link provides keymapping information and help on how to use the Deseret keyboard: 
https://help.keyman.com/keyboard/deseret/1.2/deseret
