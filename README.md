## BCOG200 - Python for Brain and Cognitive Sciences - final project
𐐒𐐗𐐉𐐘200 - 𐐑𐐴𐑃𐐱𐑌 𐑁𐐱𐑉 𐐒𐑉𐐩𐑌 𐐰𐑌𐐼 𐐕𐐱𐑀𐑌𐐮𐐻𐐮𐑂 𐐝𐐴𐐲𐑌𐑅𐐮𐑅 - 𐑁𐐴𐑌𐐲𐑊 𐐹𐑉𐐱𐐾𐐯𐐿𐐻

In this project I plan to create a translator (more accurately described as a transliterator) for the Deseret alphabet. It is a phonetic writing system used to write English, developed by the early Mormon community in the 1850s for purposes of orthographic reform and cultural differentiation. This transliterator will take English written in Latin text and transform it to the Deseret.

#### function 1
this will take Latin text input from a user.

#### function 2
this will transform the Latin text into the International Phonetic Alphabet.

#### function 3
this will transform the IPA text into the Deseret and output it for the user.
